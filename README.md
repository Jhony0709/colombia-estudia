# Colombia Estudia

Plataforma para instituciones que dictan programas en cohortes —el primer cliente es
Valida YA, bachillerato acelerado— con contenido en Markdown y video, evaluaciones con
ajustes razonables (PIAR), cartera por cuotas y aliados B2B. Multitenant, accesible
(WCAG 2.2 AA) y respetuosa de la jurisprudencia sobre mora y derecho a la educación.
